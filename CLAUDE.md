# Working rules for this repository

## DataForSEO: keep the spend down (decided by Diego, 2026-09-27)

The account is prepaid. In one session (23 to 26 Sep 2026) about US$ 12.84 went on research, more than half
of it on `domain_analytics/whois/overview` with large filtered queries. Rules:

- **Domain availability: DNS first, WHOIS last.** Check candidates with a free DNS lookup (`dnspython`, NS
  record: NXDOMAIN = probably free, any answer or NoAnswer = registered). Only confirm the 2 or 3 finalists
  with `whois/overview`, filtering by exact domain and a small `limit`. Never run open-ended WHOIS
  searches (filters on expiry, `pending_delete`, backlinks, etc.): each costs US$ 0.12 plus US$ 0.0012 per
  result, so a 100-row query is about US$ 0.24.
- **Search volume: batch keywords.** `keywords_data/google_ads/search_volume/live` costs US$ 0.09 per
  request whatever the size, and takes up to 1,000 keywords. Put every keyword and variant for a market
  into one request per location instead of several small ones. Same for `keywords_for_keywords`.
- Prefer the cheap endpoints for quality checks: `backlinks/bulk_ranks` and `backlinks/bulk_pages_summary`
  (about US$ 0.02 per request for many targets) before per-domain `backlinks/backlinks`.
- SERP live (US$ 0.002), `on_page/instant_pages` (US$ 0.00015) and screenshots are cheap; no need to ration.
- `appendix/user_data` is free and shows the balance.
- Through the MCP, call `search_volume` with `noAiMode: true` from the start: the compact mode returns only 10
  items, and repeating the request costs the full US$ 0.09 again. Parse the saved file with Python.
- Search Console: the service account in `GOOGLE_SEARCH_CONSOLE_KEY` reads both properties (and diwizi.com,
  diwizi.com.br, bigworldjobs.com, wfadigital.com, trutek.com.br). Use it from a venv (the system `cryptography`
  is broken); never print the key.

## Automated tests of the sites

- Always block `googletagmanager.com` and `google-analytics.com` in Playwright or any headless run
  (`context.route(/googletagmanager\.com|google-analytics\.com/, r => r.abort())`), so tests never reach GA4.
- The sites also skip GTM when `navigator.webdriver` is true or the UA contains `HeadlessChrome`; do not
  remove that guard. `/?internal=1` marks a browser as internal traffic (`/?internal=0` clears it).

## Sites (`sites/`)

- `googleadsfreelancer.com` (US/Canada, GTM-TB2NHZCH) and `ppcconsultancy.uk` (UK, GTM-TZDFPPMX) are static
  sites generated by `build.py`; `dist/` is committed and deployed by Cloudflare Workers Builds.
- Copy rules: no em dash (U+2014) in site text; do not publish Diego's own prices (market estimates are
  fine); no unconfirmed claims; the client "Mission AC & Plumbing" is named only in the logo strip.
- `lastmod.json` tracks a per-page content fingerprint; run `python3 build.py` twice and expect no diff.
