# googleadsfreelancer.com

Static site, generated by `build.py` into `dist/`. Deployed on Cloudflare Pages
(build command: none; output directory: `sites/googleadsfreelancer.com/dist`).

Rebuild after editing `pages_core.py` / `pages_services.py`:

    python3 build.py

## Go-live checklist

1. Cloudflare Pages → Custom domains → add `googleadsfreelancer.com` and `www.googleadsfreelancer.com`.
2. Search Console → add property (Domain, DNS verification) → submit `/sitemap.xml` → request indexing for the service URLs.
3. Add GA4 + Google Ads conversion tag (Tag Manager) in `build.py` `<head>` once the container exists; update `/privacy/`.
4. Link from diwizi.com (footer + /freelance-google-ads-specialist.html + /ppc-consultant.html) to this site.
5. Point the "Freelance Google Ads" and "PPC Consultant" ad groups of the Search campaign at the matching URLs here.
